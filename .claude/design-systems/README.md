# Design Systems

Sistemas de diseño y patrones visuales para proyectos Praxis.

## Design System Default: Premium Frontend

El design system principal y único de Praxis es **premium-frontend**, implementado como skill en `.claude/skills/frontend-design/`.

Este sistema genera interfaces premium, minimalistas, inspiradas en Stripe, Apple, Linear y Vercel usando shadcn/ui + Tailwind CSS.

## Cómo Usar

```
/frontend-design para crear interfaces con el design system premium
```

## Agregar Design Systems Personalizados

Esta carpeta está disponible para agregar tus propios design systems. Estructura recomendada:

```
design-systems/
├── README.md
└── [nombre-sistema]/
    ├── [nombre-sistema].md   # Documentación técnica
    └── images/
        └── [referencia].png  # Capturas de referencia visual
```
